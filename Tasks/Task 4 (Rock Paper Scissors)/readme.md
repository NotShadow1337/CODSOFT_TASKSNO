# Rock Paper Scissors

## Description

This is a simple Rock Paper Scissors game developed using Python. The user chooses Rock, Paper, or Scissors, and the computer randomly selects one. The winner is decided based on the game rules.

## Features

- Play against the computer.
- Random computer choice.
- Displays the winner.
- Exit the application.

---

## Sample Output

### Main Menu

```text
----- ROCK PAPER SCISSORS -----
1. Rock
2. Paper
3. Scissors
4. Exit
```

### User Wins

```text
Enter your choice: 1

You chose: Rock
Computer chose: Scissors
You win!
```

### Computer Wins

```text
Enter your choice: 2

You chose: Paper
Computer chose: Scissors
Computer wins!
```

### Tie

```text
Enter your choice: 3

You chose: Scissors
Computer chose: Scissors
It's a tie!
```

### Invalid Choice

```text
Enter your choice: 5

Invalid choice.
```

### Exit

```text
Enter your choice: 4

Thank you!
```
