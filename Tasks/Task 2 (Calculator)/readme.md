# Calculator

## Description

This is a simple command-line Calculator application developed using Python. It allows users to perform basic arithmetic operations by selecting an option from the menu.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Exit the Application

---

3. Multiplication
4. Division
5. Exit
