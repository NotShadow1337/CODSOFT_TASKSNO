# Password Generator

## Description

This is a simple Password Generator developed using Python. It generates a random password based on the length entered by the user.

## Features

- User chooses the password length.
- Generates a random password.
- Uses letters, numbers, and special characters.

---

## Sample Output

### Generate Password

```text
Enter password length: 8
Generated Password: a@7K!q2P
```

### Generate Another Password

```text
Enter password length: 12
Generated Password: 9#Lm$2Qw@8Zx
```
