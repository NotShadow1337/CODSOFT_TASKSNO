# Contact Book

## Description

This is a simple command-line Contact Book developed using Python. It allows users to store and manage contact details through a menu-driven program.

## Features

- View Contacts
- Add Contact
- Search Contact
- Update Contact
- Delete Contact
- Exit the Application

---

## Sample Output

### Main Menu

```text
----- CONTACT BOOK -----
1. View Contacts
2. Add Contact
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit
```
